Nouveautés

Android (APK)

Le plus fluide sur téléphone. Une nouvelle version s'installe par-dessus l'ancienne, la partie est gardée.

Télécharger l'APK
  1. Ouvre le fichier téléchargé.
  2. Si Android le demande, autorise l'installation d'applications pour ton navigateur ou l'app Fichiers.
  3. Touche « Installer » (Play Protect peut prévenir que l'app ne vient pas du Play Store : « Installer quand même »).

Windows

Décompresse le zip, puis lance TamagoChoupie.exe (garde les deux fichiers ensemble).

Télécharger pour Windows

Jouer dans le navigateur

Rien à installer. Dans Chrome sur Android : menu ⋮ → « Installer l'application » pour l'avoir sur l'écran d'accueil ; elle se met à jour toute seule.
