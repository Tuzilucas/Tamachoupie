# TamagoChoupie — version jouable en ligne

Jeu 3D d'aventure et de survie : Choupie, un bébé dragon né seul sur une île sauvage. Fait avec Godot 4.7. Gratuit, sans compte et sans publicité.

**Jouer : https://tuzilucas.github.io/Tamachoupie/**

Fonctionne dans le navigateur de l'ordinateur et du téléphone (Chrome, Edge, Firefox, Safari récents). La partie est
sauvegardée dans le navigateur de l'appareil.

Ce dépôt ne contient que la version exportée pour le web (`index.html`, `index.wasm`, `index.pck`…), générée
automatiquement à partir du projet Godot. Les décors utilisent des modèles libres de droits : voir [`CREDITS.md`](CREDITS.md).

## Commandes

- **Téléphone** : pouce gauche = joystick ; glisser à droite = caméra ; le bouton rond fait l'action proposée
  (caresser, cueillir, manger, dormir…) ou **sauter** ; en l'air il fait **battre des ailes**, maintenu il **plane**.
  Toucher deux fois l'écran pour passer la cinématique.
- **Ordinateur** : ZQSD / WASD ou flèches pour marcher, **Espace** pour sauter / voler / planer (maintenu),
  **F** pour souffler (fumée du bébé, flammes plus tard), **clic droit glissé** pour tourner la caméra, **molette**
  pour zoomer, double clic pour passer la cinématique.

Si le jeu rame sur un ordinateur ou un téléphone peu puissant, il passe tout seul en qualité légère ; on peut aussi
la forcer en ouvrant **https://tuzilucas.github.io/Tamachoupie/?qualite=basse**.
