# TamagoChoupie — version jouable en ligne

Jeu 3D de compagnon virtuel (Tamagotchi), fait avec Godot 4.7. Gratuit, sans compte et sans publicité.

**Jouer : https://tuzilucas.github.io/Tamachoupie/**

Fonctionne dans le navigateur de l'ordinateur et du téléphone (Chrome, Edge, Firefox, Safari récents). La partie est
sauvegardée dans le navigateur de l'appareil.

Ce dépôt ne contient que la version exportée pour le web (`index.html`, `index.wasm`, `index.pck`…), générée
automatiquement à partir du projet Godot. Les décors utilisent des modèles libres de droits : voir [`CREDITS.md`](CREDITS.md).
